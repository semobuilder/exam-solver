# exam-solver

AI 사용이 허용된 실무시험·해커톤의 작업 단계에서 사용하는 범용 Codex 스킬입니다.

조건 확인 → 완료 기준 → 최소 구현 → 실제 검증 → 이해 확인 순서로 진행합니다. Codex가 담당자별 역할을 파악해 보낼 대상과 질문을 출력하면 참가자가 시험 내 메신저로 전송하고 답변을 전달합니다. Codex는 출처·적용 범위를 구분하고, 충돌하는 조건은 추가 확인한 뒤 구현과 검증에 반영합니다.

특정 시험 문제·자료·정답을 포함하지 않습니다. 사용 가능 여부와 설치 방법은 해당 시험의 최신 안내를 따릅니다. 합격이나 점수를 보장하지 않습니다.

## 설치 요청 프롬프트

시험에서 허용한 Codex 작업 환경에 아래 내용을 입력하세요.

```text
공개 저장소 https://github.com/semobuilder/exam-solver 의 최신 스킬을 확인해.
이 시험에서 허용한 방법과 제공 환경의 스킬 설치 안내에 따라 exam-solver를 설치해.
SKILL.md와 references/field-guide.md를 함께 가져와 상대 경로를 유지해.
개인 API 키나 외부 계정을 추가하지 말고, 시험 자료를 외부로 전송하지 마.
설치·인식 여부를 확인하고 실제 호출 방법을 알려줘.
설치가 지원되지 않으면 SKILL.md를 읽고 현재 대화의 작업 지침으로 적용해.
파일을 읽은 것과 스킬 설치가 완료된 것은 구분해서 알려줘.
```

## 시험 시작 프롬프트

설치가 확인된 환경에서는 아래 한 줄로 시작합니다. 자료 읽기, 질문 출력, 계획, 구현, 검증, 이해 확인까지 스킬에 포함되어 있습니다. 스킬로 인식되지 않으면 위 설치 요청부터 진행하세요.

```text
$exam-solver
```

참가자는 출력된 질문을 담당자에게 보내고 답변을 전달하면 됩니다. 자료에 접근할 수 없거나 남은 시간이 보이지 않으면 스킬이 필요한 정보를 요청합니다. 필요할 때 “남은 시간 40분이야”처럼 상황만 추가해 주세요. 별도의 다음 단계 지시는 필요하지 않습니다.

## 사용 중 담당자 답변 전달

```text
담당자에게 확인한 답변이야:
[실제 답변]
```

후속 서술형 등 AI 사용이 허용되지 않거나 접근할 수 없는 단계에는 적용하지 않습니다. 시험 문제·자료·결과물·작업 기록을 이 공개 저장소에 업로드하지 마세요.

## 제한된 환경에서의 강화 내용

한 번 호출하는 방식은 유지하며, 필요한 단계에서 [실전 운영 가이드](references/field-guide.md)를 읽습니다. 채팅 입력과 CLI의 기능·제한을 구분하고, 짧은 모듈형 지시와 파일 기반 상태 복구, 담당자별 질문, 알고리즘의 제약·최적성·복잡도 검증, 180분 운영 예시, 실제 구현에 맞는 Handoff·설명 연습을 제공합니다.

1,000자·첨부 5개 같은 수치는 해당 회차·통로에서 확인될 때만 적용합니다. 여러 세션이나 특정 문서·빌드 도구가 항상 지원·필수라고 가정하지 않습니다. 후기는 준비의 참고자료이며 공식 명세나 채점표가 아닙니다. 특정 기출 문제나 참가자의 비공개 자료는 포함하지 않습니다.

- [Cofa 공식 Probe 안내](https://www.getcofa.com/ko/probe): 산출물·대화·도구·검증 기록과 사후 설명을 함께 평가. 대회별 배점·UI 제한을 확정하는 자료는 아닙니다.
- [10월 31일 응시자의 벨로그 후기](https://velog.io/@sjyoung/SK-하이닉스-AI-해커톤-2026-2차-예선-To-Be-Continued): 프로젝트 형식, 반복 이탈·502/503 경험. 개인 경험이며 장애의 전체 범위를 증명하지 않습니다.
- [11월 1일 익명 복기](https://gall.dcinside.com/mgallery/board/view/?id=ai_utilize&no=161961): 최적화에 매달려 전체 구현 시간이 부족했다는 개인 의견. 필수 최적성을 포기하라는 지침으로 해석하지 않습니다.
- [공개 후기 취합 글](https://aviss.kr/blog/view.php?seq=183): 추가 후기 원문을 찾는 데 사용. 세션 분할 등의 전략은 독립 확인된 고득점 사례가 아닙니다.
- [재응시 관련 11월 2일 보도](https://www.etnews.com/20261102000049): 접속 장애와 전원 재응시 방침. 실제 회차 운영은 개별 최신 안내를 확인합니다.

검색 결과의 ‘2차’가 1차 예선의 두 번째 교시를 뜻하는 경우를 구분했습니다. 날짜·플랫폼이 맞지 않는 후기를 Cofa의 고정 제약 근거로 사용하지 않습니다.

### 추가 후기 반영

질문은 결과를 바꾸는 미확인 조건이 해소되면 종료하고, 명확한 과제는 짧은 계획 뒤 구현합니다. 핵심 기능마다 선택 이유를 실제 함수·실패 동작·검증 사례와 연결해 이해를 확인합니다. 연장 공지와 타이머가 다를 때의 대응, 파일 저장부터 최종 접수까지의 단계 구분도 보강했습니다.

아래 자료를 기존 벨로그 후기·11월 1일 복기와 함께 10건으로 검토했습니다. 하이닉스 2차 관련 8건과 별도 코파톤 참여 후기 2건이며, 익명 글·댓글의 응시 여부와 성적은 독립적으로 확인하지 못했습니다. 경험에서 얻은 준비 전략이며 공식 규칙이나 고득점의 인과관계가 아닙니다.

- [비개발 응시자의 이해·설명 부담](https://gall.dcinside.com/mgallery/board/view/?id=ai_utilize&no=161498): 작업 중 이해 확인을 분산.
- [종료·서술형 전환 경험](https://gall.dcinside.com/mgallery/board/view/?id=ai_utilize&no=160824): 연장 적용을 추정하지 않고 제출 여유 확보.
