# exam-solver

AI 사용이 허용된 실무시험·해커톤의 작업 단계에서 사용하는 범용 Codex 스킬입니다.

조건 확인 → 완료 기준 → 최소 구현 → 실제 검증 → 이해 확인 순서로 진행합니다. 시험 내 업무 담당자에게 구체적인 조건을 묻고, 답변을 구현과 검증에 반영합니다.

특정 시험 문제·자료·정답을 포함하지 않습니다. 사용 가능 여부와 설치 방법은 해당 시험의 최신 안내를 따릅니다. 합격이나 점수를 보장하지 않습니다.

## 설치 요청 프롬프트

시험에서 허용한 Codex 작업 환경에 아래 내용을 입력하세요.

```text
공개 저장소 https://github.com/semobuilder/exam-solver 의 SKILL.md를 확인해.
이 시험에서 허용한 방법과 제공 환경의 스킬 설치 안내에 따라 exam-solver를 설치해.
개인 API 키나 외부 계정을 추가하지 말고, 시험 자료를 외부로 전송하지 마.
설치·인식 여부를 확인하고 실제 호출 방법을 알려줘.
설치가 지원되지 않으면 SKILL.md를 읽고 현재 대화의 작업 지침으로 적용해.
파일을 읽은 것과 스킬 설치가 완료된 것은 구분해서 알려줘.
```

## 시험 시작 프롬프트

설치가 확인된 환경에서 아래 내용을 입력하고 남은 시간을 실제 값으로 바꾸세요. 스킬로 인식되지 않으면 위 설치 요청부터 진행하세요.

```text
$exam-solver

현재 남은 작업 시간은 [실제 남은 시간]분이야.
먼저 과제 안내·README·제공 자료·기존 파일과 제출 조건을 읽고,
사용자·목표·필수 결과물·핵심 미확인 조건을 짧게 정리해.

업무 담당자에게 물어봐야 할 것은 실제 데이터와 연결한 구체적인 질문으로 만들어.
허용된 도구로 메신저에 접근할 수 있으면 직접 묻고,
접근할 수 없으면 내가 그대로 보낼 질문만 정리해 줘. 내가 답변을 전달할게.
업무 조건은 담당자에게, 환경·제출 방법은 Cofa Helper에게 구분해서 확인해.
확인된 답변을 구현 규칙과 검증 사례에 반영하고, 중요한 미확인 조건을 임의로 정하지 마.

필수 결과물부터 만들고 예상값과 실제값을 비교해 검증해.
수정했다면 관련 사례와 정상 흐름을 다시 확인해.
검증·저장·제출 시간을 남기고, 중요한 판단과 실제 검증 근거만 간단히 기록해.
마지막에는 내가 이해할 수 있도록 동작 방식·선택 이유·검증 결과·한계를 설명해.
```

## 사용 중 담당자 답변 전달

```text
담당자에게 확인한 답변이야:
[실제 답변]

이 답변으로 확정된 조건과 아직 남은 불확실성을 구분해.
기존 구현·예상값에 달라지는 부분을 반영하고 관련 검증을 다시 진행해.
```

후속 서술형 등 AI 사용이 허용되지 않거나 접근할 수 없는 단계에는 적용하지 않습니다. 시험 문제·자료·결과물·작업 기록을 이 공개 저장소에 업로드하지 마세요.
